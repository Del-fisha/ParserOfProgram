# Проект: Парсер программного кода

## Назначение

Данный проект представляет собой консольную утилиту для сбора содержимого файлов определенного типа из указанной директории и ее поддиректорий в единый текстовый файл.  Основная цель - упростить процесс агрегации кода и конфигурационных файлов для дальнейшего анализа, например, для отправки на ревью или поиска определенных паттернов.

## Описание

Программа рекурсивно сканирует указанную стартовую директорию, идентифицирует файлы с заданными расширениями (а также файлы с именами pom.xml и *.gradle), извлекает их содержимое и записывает в один выходной файл. Каждый файл предваряется именем, а затем следует его содержимое.

### Функциональность

•   **Рекурсивный поиск:**  Программа выполняет рекурсивный обход директории, включая все поддиректории.
•   **Фильтрация файлов по типу:**  Позволяет указать типы файлов, которые необходимо включить в выходной файл.
•   **Обработка исключений:** Обрабатывает исключения, возникающие при чтении или записи файлов, и предоставляет информативные сообщения об ошибках.
•   **Интерактивный ввод:** Запрашивает у пользователя стартовую директорию, директорию для сохранения, а также типы файлов для обработки.  Выполняет валидацию ввода путей.
•   **Включение файлов pom.xml и *.gradle:** Помимо фильтрации по расширению, программа также включает файлы с именами pom.xml и с расширением gradle вне зависимости от указанных типов.

### Архитектура

Программа состоит из одного класса Main, который выполняет все операции.  Ключевые методы:

•   main(String[] args):  Основной метод, который управляет потоком выполнения программы.
•   parseFiles(String[] types, File dir): Рекурсивно обходит директорию и добавляет подходящие файлы в список filesToParse.
•   getStartDir(): Получает от пользователя стартовую директорию и выполняет валидацию.
•   getFinishDir(): Получает от пользователя директорию для сохранения и выполняет валидацию.

### Используемые технологии

•   **Java:** Основной язык программирования.
•   **java.io:**  Используется для операций ввода-вывода (чтение и запись файлов).
•   **java.util.Scanner:** Используется для получения пользовательского ввода.
•   **java.util.ArrayList:** Используется для хранения списка файлов.

## Инструкция по запуску

1.  Скомпилируйте файл Main.java: javac Main.java
2.  Запустите программу: java Main
3.  Программа запросит:
    *   Стартовый путь (путь к директории, в которой нужно искать файлы).
    *   Путь сохранения (путь к директории, куда будет сохранен результирующий файл).
    *   Типы файлов через пробел (например: java txt xml).

## Замечания

•   Программа предполагает, что указанные директории существуют.  Если директория не существует, программа предложит ввести путь повторно.
•   Программа записывает содержимое файлов в текстовом виде. Бинарные файлы не будут корректно обработаны.
•   При возникновении ошибок чтения/записи, программа выводит сообщение об ошибке в консоль, но продолжает работу.
•   Включены файлы pom.xml и *.gradle для удобства анализа Java-проектов, использующих Maven и Gradle.
